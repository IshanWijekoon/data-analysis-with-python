# Data Analysis with Python

This repository contains my solutions for the [freeCodeCamp Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/) certification. Each folder is one of the five required projects, built with **NumPy**, **Pandas**, **Matplotlib**, **Seaborn**, and **SciPy**.

## Projects

| Project | What it does |
| --- | --- |
| [Mean-Variance-Standard Deviation Calculator](Mean-Varience-Standard%20Deviation%20Calculator) | Takes nine numbers, reshapes them into a 3×3 matrix, and returns mean, variance, standard deviation, max, min, and sum for rows, columns, and the full matrix. |
| [Demographic Data Analyzer](Demographic%20Data%20Analyzer) | Uses Pandas on 1994 Census data to answer questions about race, education, income, work hours, and occupation. |
| [Medical Data Visualizer](Medical%20Data%20Visualizer) | Cleans medical examination data, then draws a categorical plot of health indicators and a correlation heatmap. |
| [Page View Time Series Visualizer](Page%20View%20Time%20Series%20Visualizer) | Charts daily freeCodeCamp forum page views as a line plot, a monthly bar chart, and year/month box plots. |
| [Sea Level Predictor](Sea%20Level%20Predictor) | Fits linear regressions to global sea level data since 1880 and projects the rise through 2050. |

## Running a project

Each project has a `main.py` that runs the analysis and the unit tests.

```bash
cd "Demographic Data Analyzer"
python main.py
```

Replace the folder name with the project you want to run. The dataset for that project is already in the same folder.
